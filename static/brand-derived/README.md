# Homepage ad crop

`home-ad-photo.webp` is a crop/mask of the owner's original
`docs/brand-assets/originals/MonkeyDo AD (1).jpg`. The original is unchanged.
The connected sage frame was isolated, retaining the original photo inside it;
background outside that frame is transparent. No people or play equipment were
generated or retouched. Output is 1291 × 1650, with its full border visible using
CSS object-fit:contain. The ad's seasonal and promotional wording is excluded.

Nunito is a temporary visual match selected with the owner's permission, not an
identification of the ad's actual font. The variable font is served locally from
`static/fonts`, with its upstream SIL Open Font License. Upstream source:
https://github.com/google/fonts/tree/main/ofl/nunito

The owner also supplied five inline chat images showing pretend fishing,
climbing, foam-pit play, the toddler area and spiral-slide play. These image
attachments were visible in chat but unavailable as downloadable files in this
workspace. Original uploads are still required before adding those exact photos
to About and the three homepage cards. Do not replace them with generated photos.
