# Eighth batch — screenshot gallery

**PR [#34](https://github.com/MonkeyDo-Site/MonkeyDoWebsiteNewCode/pull/34) is draft and awaiting your review.** Please refer to the gallery number when giving a comment. This same PR and gallery will be updated as you review.

Each numbered screen has a **desktop (1440px)** and **phone (390px)** image. Click Desktop or Phone to open the full image; the expandable previews below are the same uncropped screenshots. The final column maps back to the comments in your Word document.

Start with **07–08** for the requested 732-555-0147 examples and **10–13** for the one-button confirmation flow. **21** shows the updated email subject/body. **19–20** are recovery examples for a deliberately interrupted response, not the normal booking steps.

All records and card fields here are fictional. The provider card frame is simulated; these images do not establish real Banquest iframe rendering or issuer approval. No external payment, email or storage request was sent. Clubs are hidden, and public membership purchase remains disabled. The email preview includes a mail-client-style To/Subject header for review; that header is not added to the email body. Its subject has no year/reference, and there is no repeating date/time preheader.

The ordinary booking still collects admission only after staff arrival review. Processing is visibly unconfirmed; invalid/uncertain setup cannot silently create a booking. The original unexpected legacy-flow code paths are blocked for new completed-workflow bookings; the historical legacy records remain read-only history.

No merge, hosted deployment or new integration activation has been performed for this PR. After you finish reviewing, we will merge the approved PR and prepare the pinned browser ZIP and single PowerShell deployment command.
