# Membership screens — latest details first

**Updated for your latest comment. Not deployed. PR and deployment await image review.**

The list shows one row per membership with its latest details. The status is simply Draft; the list, current detail heading and edit form have no version labels. Earlier saved details are accessible within the expandable Membership history. Editing retains the same membership ID.

The two fictional rows #M1 and #M2 are separate example memberships, not versions of one membership. No records were deleted or merged.
